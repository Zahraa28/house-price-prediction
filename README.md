# House Price Prediction - Prodigy Infotech Internship Task

This project predicts house prices using machine learning (Linear Regression) based on the Ames Housing dataset. It's affiliated with the **Prodigy Infotech Internship Program** as Task 1.

## Project Overview

- **Algorithm**: Linear Regression
- **Preprocessing**: OneHotEncoding, Standard Scaling, Imputation
- **Evaluation**: 5-Fold Cross Validation (R² Score)

## Dataset

- Train: `data/train.csv`
- Test: `data/test.csv`

## Results

- Cross-Validation R² Score: 94.25%
- Submission file created at `submission/submission.csv`
